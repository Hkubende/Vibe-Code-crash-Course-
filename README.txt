VIBE CODING — 60 MINUTE CRASH COURSE

RUN LOCALLY (NO INSTALLATION REQUIRED)
1. Extract the ZIP file if you received it as an archive.
2. Open the vibe-coding-course folder.
3. Double-click index.html.
4. The course opens in your default browser.

OPTIONAL: RUN THROUGH VS CODE + LIVE SERVER
1. Open the folder in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click index.html and choose "Open with Live Server".

NOTES
- The course content, navigation, progress tracker, copy buttons and quiz work locally.
- External links to GitHub, Node.js, VS Code and MCP documentation require internet access.
- No backend or database is required.
