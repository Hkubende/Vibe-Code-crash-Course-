01 · Introduction to Vibe Coding

5 minutes · Understand the central idea.

5 MIN

What is Vibe Coding?

Vibe coding is an approach to software development where you describe what you want to build in natural language and use an AI coding assistant to generate, explain, modify and debug code. You guide the work; the AI helps implement it.

Main concept: You provide the idea and requirements. AI assists with implementation. You run, test and verify the result.

It does not remove the need to understand programming fundamentals, security, testing or software quality.

Traditional coding

Developer writes most code directly, using programming languages and development tools.

AI-assisted / vibe coding

Developer describes tasks, reviews generated code, tests behaviour and iterates with AI.

02 · Workflow & prompting

10 minutes · Learn the repeatable development process.

10 MIN

The 7-step Vibe Coding workflow

Idea and problem definition

Identify the user, the problem and the outcome. Example: a teacher needs a simple attendance tracker.

Prompting

Describe the goal, users, features, design, technology and constraints clearly.

Planning and architecture

Ask AI to propose the file structure, components, data model and small implementation tasks.

Code generation

Let the coding assistant create or edit project files. Review the changes instead of blindly accepting them.

Integration

Connect APIs, databases, MCP servers and other external services when needed.

Testing and debugging

Run the app, reproduce errors, inspect logs and ask AI for a targeted fix. Retest the affected features.

Deployment and maintenance

Publish the application, monitor it and continue improving it based on feedback.

How to write a useful prompt

Prompt elementWhat to specify
RoleWhat expertise should the AI apply?
ObjectiveWhat should be built?
FeaturesWhat must users be able to do?
TechnologyWhich language, framework or tools?
DesignWhat should the interface look and feel like?
ConstraintsWhat must be preserved or avoided?
TestingHow should the result be checked?

Example starter prompt

Act as an experienced full-stack developer.

Build a simple school attendance website.
- Allow teachers to register students.
- Mark students present or absent.
- Show present and absent totals.
- Use a clean, responsive design.
- Use HTML, CSS and JavaScript.
- Store records in the browser for this demo.

First explain the project structure, then build it.
Explain how to run and test the application.
Tip: Break large tasks into smaller prompts. Ask the AI to plan first, implement one feature at a time, and explain important changes.

What is MCP?

MCP means Model Context Protocol. It is an open standard that lets AI applications connect to external tools and information sources through MCP servers.

Think of MCP as a structured bridge between an AI assistant and an external service.

GitHub MCP

Work with repositories, issues and pull requests when configured and authorised.

Filesystem MCP

Read or manage permitted files and folders.

Database MCP

Query supported databases with appropriate permissions.

Other integrations may include browser automation or services such as Supabase. Capabilities depend on the MCP server and the permissions granted.

MCP official documentation ↗

Plugins and extensions

Plugins and extensions add capabilities to an application. In a coding editor, extensions can format code, identify issues or add AI assistance.

ExamplePurpose
GitHub Copilot extensionAI coding assistance in VS Code.
PrettierAutomatically formats code.
Live ServerServes and refreshes a local website during development.
ESLintFinds common JavaScript code problems.
Know the difference: MCP is a connection protocol; a plugin or extension adds functionality; an API is an interface software uses to communicate with another system. They are related, but not interchangeable.

Create and open a project

Open Git Bash and run these commands one by one:

mkdir vibe-project
cd vibe-project
code .
  • mkdir creates a folder.
  • cd moves into that folder.
  • code . opens the current folder in VS Code. If unavailable, open VS Code manually and choose File → Open Folder.

Use Git Bash inside VS Code

  1. Open VS Code.
  2. Choose Terminal → New Terminal.
  3. Open the terminal profile dropdown.
  4. Select Git Bash. If it is not listed, configure or select its executable in terminal profile settings.

Useful terminal commands

CommandPurpose
pwdShow current directory.
lsList files and folders.
mkdir appCreate a folder named app.
cd appEnter the app folder.
touch index.htmlCreate a file.
npm installInstall dependencies listed in package.json.
npm run devRun a project's configured development script.

VS Code is where you edit and manage files. Git Bash is where you run terminal commands. Node.js is only required for projects that use Node tooling.

Git versus GitHub

Git

A version-control system that records changes to files and lets you revisit earlier versions.

GitHub

A cloud platform for hosting Git repositories, collaborating and managing software projects.

Create a GitHub account ↗ · GitHub documentation ↗

Core Git vocabulary

TermMeaning
RepositoryProject files plus their version history.
CommitA recorded snapshot of staged changes.
PushSend local commits to a remote repository.
PullFetch and integrate remote changes.
CloneCopy a remote repository to your computer.
BranchA separate line of development.
MergeCombine changes from different branches.
Pull requestPropose and review changes before merging.

Practical: publish your project to GitHub

Create a GitHub account

Go to GitHub and sign in or create a free account.

Open your project in VS Code

Use File → Open Folder to open the project folder.

Initialize Git and commit

Run the following in the VS Code terminal:

git init
git add .
git commit -m "Initial project"

Create an empty GitHub repository

On GitHub, choose New repository and name it student-attendance. For this walkthrough, do not pre-create a README, licence or .gitignore.

Connect and push

Copy the repository URL from GitHub. Replace USERNAME with your GitHub username:

git remote add origin https://github.com/USERNAME/student-attendance.git
git branch -M main
git push -u origin main

Follow GitHub's sign-in prompt if authentication is requested.

Essential Git commands

git status                         # check changed files
git add .                          # stage changes
git commit -m "Describe the change" # save a snapshot
git push                           # upload commits
git pull                           # get and integrate remote changes
git clone REPOSITORY_URL           # download a repository
git log                            # view commit history
Security rule: Never commit passwords, API keys, private tokens or secret values. Add sensitive local files such as .env to .gitignore. Review staged files before pushing, especially to public repositories.

06 · Practical: build a local application

15 minutes · Turn a prompt into a working website.

15 MIN

Project: Student Attendance Manager

Learners use an AI coding assistant in VS Code to generate a small attendance application with HTML, CSS and JavaScript.

Step 1 — Create the folder

mkdir student-attendance
cd student-attendance
code .

Step 2 — Prompt the AI assistant

Build a student attendance management website using
HTML, CSS and JavaScript.

Requirements:
- Add students by name.
- Mark each student present or absent.
- Display total, present and absent counts.
- Show students in a table.
- Add search and a date selector.
- Use a clean, responsive design.
- Save demo data in browser localStorage.

Create index.html, style.css and script.js.
Explain how to run and test the application.

Step 3 — Understand the files

FilePurpose
index.htmlPage structure and content.
style.cssColours, layout and appearance.
script.jsInteractions and application logic.

Step 4 — Run locally

Option A: Live Server extension

  1. Install Live Server in VS Code.
  2. Right-click index.html.
  3. Choose Open with Live Server.
  4. Your browser opens the local website, usually at a localhost address.

Option B: Node-based local server

npx serve .

Open the local address printed in the terminal. The first run may download the serve package and therefore needs internet access.

Step 5 — Improve it with another prompt

Improve the existing attendance application:
1. Add CSV export.
2. Improve the dashboard layout.
3. Ensure attendance totals update immediately.
4. Preserve all existing features.
5. Test the main user flows and fix errors.
Explain which files you changed.

Step 6 — Test and verify

Try adding students, changing attendance status, searching, refreshing the page and exporting records. Check that counts and saved data behave as expected.

Practical outcome: A working local attendance website, plus a GitHub repository containing its source code.
